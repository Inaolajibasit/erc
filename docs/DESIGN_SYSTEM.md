# ERC Design System

## Design Philosophy

Editorial sport meets Lagos street culture.

Minimal interface.
Maximum photography.
Strong typography.
Purposeful motion.

---

## Colour

Primary background:

#F3F3F0

Primary foreground:

#111111

Pure white can be used selectively:

#FFFFFF

Muted:

#A6A6A0

Borders:

rgba(17, 17, 17, 0.15)

Accent colour:

#C95941

The accent should never dominate the website.

Use the accent for selected calls to action, route markers, active controls and small moments of emphasis. Keep the majority of the page in off-white, black and muted neutrals so the red remains editorial rather than decorative.

---

## Typography

Primary display type:

Bebas Neue.

Use Bebas Neue for the main editorial headlines, oversized statements and cropped footer typography. Its condensed proportions support strong vertical rhythm and intentional line breaks.

Font treatments:

- Regular: default display headlines and navigation-scale statements.
- Bold: key words, calls to action and high-priority section moments where the hierarchy needs more weight.
- Italic: short supporting phrases, cultural notes and selected emphasis. Use sparingly so italic remains a signal rather than a texture applied everywhere.

Do not italicise long paragraphs or combine bold and italic across entire headlines. Keep hierarchy clear through scale, weight, case and spacing before adding more styling.

Technical/meta:

- Geist Mono
- IBM Plex Mono

Use the mono face for dates, distances, route labels, event metadata and development status labels. Keep metadata readable at mobile widths; do not reduce it below the smallest accessible text size to preserve density.

Typography style:

- large display text
- tight tracking
- aggressive scale differences
- small metadata
- intentional line breaks

Example:

WE
RUN
LAGOS.

Metadata:

SAT / 06:30 / 10KM / VI

---

## Spacing

Use generous whitespace.

Desktop content width:
approximately 1440px max.

Page gutter:
Desktop: 32–48px
Tablet: 24px
Mobile: 16–20px

Section spacing:
Large.

Do not cram sections together.

---

## Borders

Thin:
1px

Low contrast.

Borders should help structure editorial layouts.

---

## Buttons

Primary button:

[ JOIN THE RUN ↗ ]

Usually pill-shaped but restrained.

Secondary action may be text + arrow.

Hover:

- subtle background inversion
- arrow movement
- text shift

Do not create giant glossy buttons.

---

## Images

Images should sometimes use:

- landscape editorial crops
- tall portrait crops
- full bleed
- asymmetric grid
- subtle scale animation
- reveal masks
- horizontal movement

Photography > illustration.

---

## Motion

Motion vocabulary:

- directional
- smooth
- kinetic
- controlled

Allowed:

- masked image reveals
- horizontal scroll
- parallax
- typography movement
- route drawing
- hero scaling
- video transitions
- count-up numbers
- marquee
- cursor contextual changes

Avoid:

- bouncing UI
- random rotations
- excessive stagger effects
- animation on every element
- dramatic spring animations
- floating decorative objects everywhere

---

## Accessibility

All essential content must remain available with animation disabled.

Respect:

prefers-reduced-motion

Text over photography requires appropriate contrast.
